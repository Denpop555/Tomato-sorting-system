# Tomato-sorting-system

Paper title: A Pressure-Insensitive Flexible Bend Sensor for Agricultural Object Size-Sorting Applications

Brief description: A regression forest model is used to establish an evaluation system with three parameters: diameter, height, and weight. Specifically, 50 resistance data points are collected for each of the 7 tomato samples, resulting in a total of 350 samples. These samples are then randomized and divided into a training set and a test set at a ratio of 7:3.
 
Usage instructions: The 'piper_end_pose' and 'piper_gripper_ctrl' are the header files, the 'main0710' is the main function.
